# Ricardo Ledan

AI systems engineer and independent researcher. I build retrieval systems, developer tools, and interactive software.

My current research focuses on how computational systems represent historical evidence, provenance, and scholarly disagreement, particularly in Haitian and Black diasporic history.

## Selected Work

**[Rasin](https://rasin.ai/)**  
A research platform in development for Haitian history, designed to help readers navigate multilingual sources, examine historical claims, and trace competing interpretations back to their evidence.

**[maxslomo](https://maxslomo.ai/)**  
An interactive audio app for reshaping music in the browser through playback controls, sound effects, stem mixing, and audio-reactive visuals.

**[Semantic Code MCP](https://github.com/smallthinkingmachines/semantic-code-mcp)**  
Codebase search for AI coding tools, combining syntax-aware chunking, local embeddings, keyword search, and relationships between calls and imports.

**[Video Context MCP](https://github.com/smallthinkingmachines/video-context-mcp)**  
Video search and inspection for AI tools, using timestamped transcripts, keyframes, OCR, and semantic retrieval.
